# Testing Markdown Reader with ALISHA

ALISHA is an offline neural voice reader for developers and researchers.

## Features
- **Zero API Keys:** Everything runs locally on your machine.
- **Privacy First:** Your code, notes, and PDF books never leave your computer.
- **Natural Voices:** High-fidelity male and female voices.

### Code Block Handling
Here is a sample TypeScript function:

```typescript
function greet(name: string): string {
    return `Hello, ${name}!`;
}
```

Notice that ALISHA smoothly skips or summarizes raw code blocks so you get a natural audio listening experience.
